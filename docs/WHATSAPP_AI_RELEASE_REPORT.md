## Start and use

Run `pnpm dev:api`, keep it running, and open http://127.0.0.1:3000/setup. Select your provider and supported model ID, enter the key and copy the pairing code. Reload/load `apps/extension/dist`. Save Reply instructions and verified Business information; pair the backend and explicitly choose automatic suggestion consent. Open WhatsApp and wait for Chat ready, then use a new incoming message. Review/edit, insert, and send manually.

Setup-entered keys and pairing expire after restart. The backend currently stores no durable customer records. The extension never receives a provider key. Do not put keys in instructions or chat.
